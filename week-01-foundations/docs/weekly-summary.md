# Week 1 — Data preparation and foundations

## Scope

- Profile source files and identify missing, duplicate and invalid values.
- Clean the sales dataset and standardise date, text and numeric fields.
- Perform exploratory analysis using basic SQL aggregations.
- Build a foundational Power BI report for sales overview.

## Deliverables

- Data-quality checklist and cleaned dataset definition.
- Basic sales, profit and category SQL queries.
- Initial Power BI report with KPI cards and visual trends.
