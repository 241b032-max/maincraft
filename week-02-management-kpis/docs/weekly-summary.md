# Week 2 — Integrated KPIs and management dashboard

## Scope

- Combine sales, customer, product and geography data using SQL JOINs.
- Calculate management KPIs from a consistent reporting grain.
- Design a management dashboard for regular performance monitoring.

## Deliverables

- Joined reporting dataset.
- KPI query set for sales, profit, orders and average order value.
- Management dashboard specification and draft report.
